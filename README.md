# Portfolio — Personal Developer Portfolio
My personal portfolio website. Built to showcase my projects, skills, and
experience in a clean and fast format. Sections include about me, tech stack,
featured projects, and contact.
Live: [portfolio-anmol-beta.vercel.app](https://portfolio-anmol-beta.vercel.app)
---
## Tech Stack
- React (with TypeScript)
- Vite (build tool)
- Tailwind CSS v4
---

## Setup
```bash
git clone https://github.com/hck-anmol/Portfolio_Anmol.git
cd Portfolio_Anmol
npm install
npm run dev
Opens at http://localhost:5173.

To build for production:
bash

npm run build
Output goes to the dist/ folder, ready to deploy on Vercel or Netlify.
